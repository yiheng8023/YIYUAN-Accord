# YIYUAN Accord v2.0.1-preview.1

This is a public preview of a bounded presentation and usability repair over
the immutable v2.0 release. It invites representative use and counterexamples;
it is not a production-stability or general-availability claim.

## What changed

- The Codex and Claude Code manifests identify the individual publisher as
  `yiheng8023`, link the author profile, and use the Accord repository as the
  project website and source.
- The Codex package uses the wordless YIYUAN NEXUS mark for its composer icon
  and logo. The source package retains the trademark boundary in `NOTICE`.
- The English and Chinese READMEs now lead with user value, show the shortest
  install and confirmation path, preserve update/removal/rollback guidance,
  and expose the project maturity and evidence ceiling before maintainer detail.
- The verifier admits strict SemVer pre-release identifiers, binds the icon
  asset into package identity, and requires the public-preview release channel
  to agree with the GitHub pre-release contract.
- The immutable v2.0 behavior contract is separated from this distribution
  version. Unchanged contract, Skill and exact exposure keep their bounded
  observations; the changed package and reader path require current checks.

No Runtime, Hook, MCP server, App, state store, installer, background process,
or automatic user-configuration mutation was added.

## Install

```powershell
codex plugin marketplace add yiheng8023/YIYUAN-Accord --ref v2.0.1-preview.1
codex plugin add yiyuan-accord-codex@yiyuan-accord
```

Restart the host, start a new task, and confirm the plugin and Skill are listed
before using them. The full activation, update, removal, rollback, Claude Code,
and verification paths are in the repository README.
