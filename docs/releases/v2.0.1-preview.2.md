# YIYUAN Accord v2.0.1-preview.2

This Public Preview repairs Claude distribution and lifecycle presentation over
the immutable v2.0 contract. It does not change the portable Skill semantics or
promote packaging compatibility into cross-surface behavior proof.

## What changed

- The Claude package now presents the human name `YIYUAN Accord for Claude`,
  matching the host-qualified Codex presentation while keeping the technical
  package IDs stable.
- The repository now contains an official Claude marketplace catalog. Claude
  Code can install it persistently from the repository, and current Claude web
  chat, the Claude Desktop Chat tab and Cowork can add repository marketplaces.
- The bilingual READMEs distinguish persistent marketplace installation from
  session-only `--plugin-dir` loading, and distinguish clone, installation,
  enablement, Skill visibility and effective behavior.
- The verifier and regressions fail closed on Claude display-name, marketplace
  source, description and version drift. The official Claude strict validator
  remains an additional current-host format check.

No Runtime, Hook, MCP server, App, state store, background process or automatic
user-configuration mutation was added. Existing representative behavior
evidence remains bound to its exact immutable v2.0 adapter contract, Skill,
projection and session. Because this distribution-only repair leaves the
behavior-bearing adapter contract and Skill unchanged, those bounded results
remain applicable without becoming a new full preview.2 behavior replay. The
preview.2 local replay proves installation, enablement, Skill discovery and one
explicit direct-load invocation only; it does not establish implicit invocation
or cross-surface equivalence.

## Install

For a persistent Claude Code installation:

```powershell
claude plugin marketplace add yiheng8023/YIYUAN-Accord@v2.0.1-preview.2
claude plugin install yiyuan-accord-claude@yiyuan-accord
```

For Claude web chat, the Claude Desktop Chat tab or Cowork, open **Customize**,
open **Plugins**, add a marketplace from the Accord GitHub repository, then
install **YIYUAN Accord for Claude**. Confirm the Skill is visible in a new chat
before judging activation. These UI surfaces may follow the repository rather
than an immutable tag, so record the exact displayed version and revision.

The local `--plugin-dir` route remains a session-scoped development and
evaluation path, not persistent installation.
