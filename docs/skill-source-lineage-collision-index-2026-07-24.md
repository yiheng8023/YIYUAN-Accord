This index joins existing repository evidence. It is not a new live CC Switch,
Agent Home, or host inventory.

The builder consumes seven dated records from July 18, 19, and 23 and binds
their exact file hashes. Mixing those dates does not create a current runtime
snapshot. Every occurrence keeps its own observation date, representation

## Boundary

The index does not read the live CC database, settings, credentials, Agent
Home, Skill bodies, or private runtime content. It performs no network fetch.
Its selected-sample group derives from the already recorded local hashes and
public Git-history evidence in the overlap matrix; rebuilding the index does
not re-scan those external surfaces.
It does not prove host visibility, loader invocation, behavioral equivalence,
Matt or Superpowers superiority, residual self-authored gaps, cross-device
equality, current projection truth, or safe migration and deletion.

It authorizes no install, enable, disable, relink, projection repair,
migration, cleanup, deletion, commit, push, release, or publication.

The machine record is
[`registry/skill-source-lineage-collision-index-2026-07-24.json`](../registry/skill-source-lineage-collision-index-2026-07-24.json).
Reproduce it with:

```powershell
python -B scripts\build_skill_source_lineage_collision_index.py
```

Use the index to bind one exact Skill and occurrence before a fresh source,
host, or behavior check. Re-observe only what that decision requires; unknown
or stale fields do not become residual-gap evidence.
