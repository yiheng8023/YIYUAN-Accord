## Fixed scenario and lifecycle sequence

The disposable scenario uses the user-bound `Pitch` example:

- `stand-alone video` initially has no canonical repository definition;
- Pitch-to-Video cardinality and deletion behavior are initially unresolved;
- a draft implementation uses cascade deletion before accountable acceptance.

The harness later injects the same frozen human decisions into every arm:

- a stand-alone Video has `lessonId == null`;
- one Pitch may be referenced by multiple stand-alone Videos;
- deletion of a referenced Pitch is restricted rather than cascaded;
- Pitch records packaging intent, not an implementation plan.

Each arm then crosses four fresh-thread phases:

1. ambiguity and contradiction elicitation;
2. semantic modeling and a sparse decision record;
3. specification consumption;
4. implementation-conflict review plus bounded handoff.

Fresh threads make repeated clarification and semantic loss observable instead
of letting conversational memory hide them. The portable authority carrier is
required, but the literal filename `CONTEXT.md` is not.

## Common hard gates

Every treatment receives identical facts, frozen human decisions, private
oracle, mutation boundary, and hard standards. It must:

- retain accepted term and decision identities across all four phases;
- keep unresolved material unresolved before human acceptance;
- separate domain language from implementation plans;
- create an ADR-equivalent record only for a hard-to-reverse, surprising,
  real-trade-off decision;
- detect the restrict-versus-cascade conflict before release or closure;
- prevent notes, projections, specifications, reviews, and handoffs from
  self-promoting into authority;
- avoid invented user decisions and writes outside the disposable root.

Terminal correctness cannot erase an earlier semantic contradiction,
unauthorized promotion, or lost decision.

## Direction falsification

The protocol can reject several attractive stories:

- If native meets the same hard gates without a material continuity or burden
  disadvantage, this scenario does not justify mandatory grilling.
- If the local monolith is more reliable than the current composition, current
  upstream structure does not justify a CC update.
- If the current composition is more reliable and cheaper under the fixed
  measurements, it becomes a portfolio-review candidate, not an automatic
  replacement.
- If all three fail the same boundary, first inspect the carrier, scenario,
  host delivery, and existing composition. Do not jump to a self-authored
  Skill.
- If loader or treatment delivery is unproved, report association only.

Directional measurements include clarification and repeated-clarification
counts, accepted-term and decision retention, contradiction detection,
unauthorized promotions, human burden, semantic-delta completeness, host
exposed token counts, latency, and treatment-fidelity evidence.
