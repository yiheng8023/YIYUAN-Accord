## Process Loss Cross-Cut

The report substantively discusses the mechanism the user described as
process loss, although it does not unify it under that name. Its sections on
long-horizon consistency, collaboration conversions, lifecycle propagation,
and delivery-chain attenuation cover:

- multiplicative decay across chained steps and errors that propagate from
  earlier turns;
- loss between human intent, machine specification, machine output, and human
  validation;
- implicit constraints and institutional knowledge that fail to survive a
  session or Agent boundary;
- ambiguous upstream inputs that are treated as authoritative downstream and
  amplify correction cost;
- local coding gains that attenuate before project and release outcomes.

Because each transformation's output can become the next transformation's
input, a small unobserved distortion can change later decomposition, routing,
delegation, implementation, review, and acceptance decisions. This creates a
cascade from local process loss to global end-to-end inconsistency; a correct
final-looking artifact cannot by itself prove that the chain stayed faithful.

This is classified as substantive mechanism coverage with incomplete
structural modeling. The report does not yet provide one cross-domain taxonomy,
hop-by-hop invariants, cumulative loss budgets, downstream blast-radius
measurement, or a falsifiable protocol spanning compression, handoff,
delegation, routing, and software-lifecycle transformations. Those omissions
must remain visible in the Harness coverage and acceptance model.
