# Discovery Index Reference Cohort

## Decision

The six `discovery-index-only` sources already present in the bounded
22-source inventory have now received an exact-revision, entry-surface static
review. All six remain lead or mechanism references. None becomes an ordinary
Skill candidate, a trusted child-source proxy, a manager replacement, or an
installation route.

Three revisions were unchanged from the 2026-08-02 inventory. Three moved:

- `github/awesome-copilot` changed materially across Skills, plugin metadata,
  workflows, executable code, and learning content;
- `sickn33/agentic-awesome-skills` changed materially across its catalog,
  plugins, code, and Skill projections;
- `VoltAgent/awesome-agent-skills` changed only its README by six inserted
  lines and still contains no local `SKILL.md` payload.

These changes prove source drift, not incremental Harness coverage or value.
No child source was opened because the current demand and capability evidence
does not expose a specific uncovered cell requiring one.

[`skill-portfolio-discovery-index-reference-cohort-2026-08-06.json`](../../registry/skill-portfolio-discovery-index-reference-cohort-2026-08-06.json).

## Bounded cohort and stop rule

The cohort was fixed to the six discovery indexes already named in
`skill-portfolio-inactive-source-candidate-pool-2026-08-02`:

1. `ComposioHQ/awesome-claude-skills`;
2. `github/awesome-copilot`;
3. `alirezarezvani/claude-skills`;
4. `VoltAgent/awesome-agent-skills`;
5. `sickn33/agentic-awesome-skills`;
6. `helloianneo/awesome-claude-code-skills`.

The stop rule required one current default-branch revision, selected Git
object identities, drift classification, entry and license boundaries, and
one reference-only disposition per source. It prohibited following child
links, itemizing the catalogs, installing dependencies, running third-party
code, or changing any Agent, manager, consumer, Plugin, App, MCP, Hook, or
account state.

Blob-filtered no-checkout clones used one temporary operating-system root
outside all discovery roots. After review, the exact root was sent to the
Windows Recycle Bin. No upstream payload was vendored into this repository.

## Source dispositions

### Composio aggregate

`ComposioHQ/awesome-claude-skills` remains at
`be2a406907dbc61b73e6827ded415c96139d13a2`. It mixes a large lead index with
bundled Skills and an external-app plugin. The entry surface crosses API-key,
authentication, service, MCP gateway, account-data, and real-action
boundaries. Its README declares Apache-2.0 but also says individual Skills may
carry different licenses; no root license file was present.

Disposition: `integration-index-and-bundled-payload-reference-only`.

### GitHub Copilot community repository

`github/awesome-copilot` advanced to
`a7fdcd50062528c9ba5e3ecb662e2c5dc53355f8`. The endpoint diff spans 326
paths, including seven changed `SKILL.md` paths and 103 plugin metadata paths;
the current tree contains 417 `SKILL.md` files. GitHub ownership does not turn
community contributions into built-in or universally official capabilities,
and its Copilot marketplace path is not CC-managed.

Disposition: `official-community-index-and-copilot-payload-reference-only`.

### Multi-host mixed catalog

`alirezarezvani/claude-skills` remains at
`aa8d778811a557a2c28ccadda4cf3d0bd028a4cc`. Its 4,721-file tree contains
generated host projections, 798 `SKILL.md` paths, hundreds of executable-like
paths, plugins, Hooks, MCP configuration, and direct installers. Advertised
cross-host support and generated path counts are source claims, not exposure,
instruction-delivery, behavior, or portability evidence.

Disposition: `large-mixed-multihost-catalog-reference-only`.

### README-only lead indexes

`VoltAgent/awesome-agent-skills` advanced to

## Claim ceiling

This checkpoint proves six dated default-branch revisions, selected Git object
identities, three source-drift observations, and a bounded static
classification. It does not prove child-source identity or quality, candidate
suitability, runtime health, instruction delivery, behavior, value, security,
portability, manager suitability, a residual gap, or production readiness.

The 17-candidate pool remains unchanged. Targeted discovery may reopen only
for one exact demand-linked child or mechanism with its own source, license,
dependency, account/data, authority, fallback, cleanup, and verification
contract.
