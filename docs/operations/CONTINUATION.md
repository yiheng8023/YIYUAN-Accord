## Stable product boundary

The Harness is an open, Agent-neutral, demand-driven human-Agent collaboration
quality harness. Its durable outputs are a methodology, an open minimum
quality-conformance profile, and thin executable reference adapters. It is not
an Agent runtime, capability catalog or manager, generic control plane, wire
protocol, identity system, or universal audit log.

The user supplies goal-level demand, domain facts and judgment, exact boundary
authorization, corrections, and accountable final acceptance. The Agent owns
capability observation and gap detection, minimum-sufficient routing, code and
conversation carrier choice, authorized mechanics, recovery, verification,
release, reconciliation, and cleanup. Human authorization and Agent execution
must remain distinct.

v0.2 is an immutable bounded calibration milestone only. Its candidate.5
profile and measured adapters cannot become the v1 product by inheritance or
byte rewriting. Codex-first is the proof order, not a portable-core dependency;
current O5 requires live matched evidence through a distinct host or runtime.
